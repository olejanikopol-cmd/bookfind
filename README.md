# BookFind

Локальный офлайн-сервис «где я читал». Фотографируете или сканируете страницу бумажной
книги (либо вставляете текст) — BookFind находит это место в файле книги (epub/fb2/txt) и
показывает главу, процент, оценку страницы и цитату. Тот же процент можно превратить в
секунду аудиокниги на YouTube.

Всё работает на вашей машине: OCR, индекс книги и выравнивание с субтитрами. В интернет
сервис ходит только за субтитрами к YouTube (через `yt-dlp`), и то — один раз на видео.

## Что нужно

| Зависимость | Зачем | Проверка |
| --- | --- | --- |
| Node.js ≥ 20 | сам сервис | `node -v` |
| `ffmpeg` | подготовка фото к OCR | `ffmpeg -version` |
| `yt-dlp` | субтитры YouTube | `yt-dlp --version` |
| `data/tessdata/rus.traineddata`, `eng.traineddata` | модели Tesseract | см. ниже |

Без `ffmpeg` фото распознаются хуже (нет предобработки), без `yt-dlp` не работает поиск
времени в аудио, без `tessdata` — распознавание фото (поиск по тексту работает всегда).
Наличие всего этого видно в правом верхнем углу страницы и в `GET /api/health`.

Модели Tesseract кладутся в `data/tessdata` (≈8 МБ, качаются один раз):

```bash
mkdir -p data/tessdata
curl -L -o data/tessdata/rus.traineddata https://github.com/tesseract-ocr/tessdata_best/raw/main/rus.traineddata
curl -L -o data/tessdata/eng.traineddata https://github.com/tesseract-ocr/tessdata_best/raw/main/eng.traineddata
```

## Запуск

```bash
npm install
npm start          # http://localhost:7788
npm run dev        # то же с перезагрузкой при правках
PORT=7799 npm start
```

В терминале появятся адрес для компьютера, LAN-адреса и QR-код: с телефона в той же Wi-Fi
страница открывается по QR и работает с камеры. По умолчанию сервер слушает `0.0.0.0`.

## Как пользоваться

1. **Библиотека** — загрузите файл книги (`.epub`, `.fb2`, `.txt`). Книга один раз
   разбирается, индексируется и лежит в `data/books/<id>/`, повторная загрузка того же
   файла отвечает из кэша.
2. **Где я** — сфотографируйте страницу (или вставьте текст) и нажмите «Найти». В ответе:
   глава, процент, оценка страницы, цитата и уровень уверенности.
3. **Аудио** — вставьте ссылку на аудиокнигу на YouTube. Если позиция уже найдена,
   нажмите «Секунда в аудио»: BookFind скачает субтитры, выровняет текст книги с речью и
   даст ссылку `youtu.be/...?t=1234` плюс QR для перехода с телефона.
4. **Закладки** — сохраняйте найденные места с цитатой и ссылкой на аудио.

Проверка страницы: используйте режим без вспышки, ровный свет и всю страницу в кадре.
Точность распознавания видна в ответе (`ocr.confidence`), а уверенность поиска — как
`confidence: high|medium|low`.

## API

| Метод | Путь | Тело / параметры | Что делает |
| --- | --- | --- | --- |
| GET | `/api/health` | — | версия Node, наличие ffmpeg/yt-dlp/tessdata, число книг |
| GET | `/api/books` | — | список книг |
| POST | `/api/books` | `{ name, dataBase64 }` | загрузить книгу (или ответить из кэша) |
| DELETE | `/api/books/:id` | — | удалить книгу |
| POST | `/api/locate` | `{ bookId, text }` или `{ bookId, imageBase64 }` | найти место в книге |
| POST | `/api/audio/link` | `{ bookId, youtubeUrl, wordPosition }` или `{ youtubeUrl, text }` | секунда в аудио + ссылка + QR |
| GET | `/api/subtitles/:videoId` | `?lang=ru` | диагностика субтитров (слов, длительность, кэш) |
| GET | `/api/bookmarks` | `?bookId=` | список закладок |
| POST | `/api/bookmarks` | `{ bookId, title, percent, pageEstimate, quote, youtubeUrl }` | добавить закладку |
| DELETE | `/api/bookmarks/:id` | — | удалить закладку |
| POST | `/api/shutdown` | — | остановить сервер |

Пример без интерфейса:

```bash
curl -s localhost:7788/api/locate -H 'Content-Type: application/json' \
  -d "{\"bookId\":\"<id>\",\"text\":\"фрагмент страницы, который вы видите\"}" \
  | jq '{chapterTitle, percent, pageEstimate, coverage, quote}'
```

## Тесты

```bash
npm test                             # нормализация, индекс, OCR-текст, epub/fb2/txt, VTT, HTTP
node --test test/bookIndex.test.js   # один файл
```

Тесты не требуют сети, `yt-dlp` и `tessdata`: EPUB-фикстура собирается в памяти как
несжатый ZIP, субтитры берутся из кэша `data/subtitles`.

## Как это работает

- **Нормализация** (`server/normalize.js`) — регистр, `ё→е`, пунктуация → пробелы,
  гомоглифы (латинские `c`, `o`, `p`, `x` из OCR → кириллица). Важно: длина строки
  сохраняется посимвольно, поэтому найденные смещения слов применимы к исходному тексту и
  цитата вырезается из книги, а не из нормализованной копии.
- **Индекс** (`server/bookIndex.js`) — слова + позиции, deletion-индекс (удаление одной
  буквы) для опечаток OCR, голосование по совпавшим словам с весом IDF. Дальше кандидат
  проверяется честно: доля покрытия и длина непрерывного участка.
- **Поиск** (`server/locate.js`) — не больше 140 слов запроса, минимум 4; отдаёт главу,
  процент, оценку страницы и цитату.
- **Аудио** (`server/vtt.js`, `server/align.js`) — субтитры YouTube приходят как «roll-up»
  (одна и та же фраза повторяется в нескольких репликах), поэтому слова склеиваются с
  дедупликацией; затем редкие слова книги ищутся в речи и берётся секунда начала фразы.

## Ограничения

- Оценка страницы приблизительная: она считается от процента и медианной длины страницы
  из epub/fb2, а не из бумажного издания.
- Секунда аудио — из субтитров, а не из звука: расхождение 2–3 секунды (плюс возможные
  вступления и «отбивки» в самом видео).
- Книга должна быть текстом: PDF и сканы без текстового слоя не поддерживаются.
- Ссылка на видео живёт столько, сколько живёт видео на YouTube; субтитры кэшируются в
  `data/subtitles/`.

## Данные

```
data/books/<id>/book.json    текст, главы, слова, смещения
data/books/<id>/index.json   пословный индекс
data/tessdata/               модели Tesseract
data/subtitles/              кэш субтитров YouTube
data/bookmarks.json          закладки
```

Каталог `data/` в `.gitignore` — книги и закладки не попадают в репозиторий.
